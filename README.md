# Big Data Sales Analytics

## Project Overview
This project analyzes online retail sales data using Python, SQL, SQLite, and Power BI to identify sales trends and generate business insights.

## Tools and Technologies
- Python
- Pandas
- SQL
- SQLite
- Power BI

## Project Files
- `clean_sales_data.py` – Cleans the sales dataset.
- `load_sqlite.py` – Loads data into SQLite.
- `run_sql_queries.py` – Executes SQL queries.
- `sales_analysis.py` – Performs sales analysis.
- `sales_insights.py` – Generates business insights.
- `sales_queries.sql` – Contains SQL queries.
- `Big_Data_Sales_Analytics.pbix` – Power BI dashboard.

## How to Run
1. Install Python and the required libraries.
2. Place the dataset in the appropriate `data` folder.
3. Run `clean_sales_data.py`.
4. Run `load_sqlite.py`.
5. Run `run_sql_queries.py` and the analysis scripts.
6. Open the Power BI file in Power BI Desktop.

## Objective
To analyze retail sales data, identify top-performing products and customers, and understand revenue trends using data analytics tools.
